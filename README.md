Un script profesional para sincronizar tu estado de Discord con la letra de lo que escuchas en Spotify en tiempo real, con un modo terminal visual impresionante.

> **Developer:** [Hellsa](https://github.com/Hellsa)

---

## ✨ Características

-  **Discord Sync:** Actualiza tu estado personalizado de Discord con la letra actual.
-  **Rainbow Terminal:** Modo visual con letras gigantes y colores arcoíris en la terminal.
-  **Anti-Ban System:** 
  - User-Agent de navegador real.
  - Cooldown de 2-3 segundos entre actualizaciones.
  - Jitter aleatorio para simular comportamiento humano.
-  **Configurable:** Elige fuentes y colores directamente desde el menú.

## 🚀 Instalación

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/Hellsa/discord-spotify-lyrics.git
   cd discord-spotify-lyrics
   ```

2. **Instala las dependencias:**
   ```bash
   npm install
   ```

3. **Configura el entorno:**
   Renombra `.env.example` a `.env` y rellena tus datos:
   - `DISCORD_TOKEN`: Tu token de usuario de Discord.
   - `SPOTIFY_CLIENT_ID`: De la consola de Spotify.
   - `SPOTIFY_CLIENT_SECRET`: De la consola de Spotify.

4. **Ejecuta el script:**
   ```bash
   npm run start
   ```

---

## ⚙️ Modos Disponibles

1. **Discord Lyrics Status**: Actualiza tu perfil de Discord. Diseñado para ser discreto y seguro.
2. **Terminal Lyrics Mode**: Ideal para tenerlo en una segunda pantalla. Puedes elegir entre:
   - **Colores**: Arcoíris, Cian, Verde Matrix, Rosa.
   - **Fuentes**: Standard, Big, Mini (para letras largas).
